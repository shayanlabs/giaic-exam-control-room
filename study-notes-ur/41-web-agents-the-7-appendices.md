# 41. The 7 Appendices

## Aasan Zabaan Mein Samjho

Web-agents course ke aakhir mein saat choti choti appendices hain jo baad ke bare courses ke concepts ko web surface pe map karti hain. Sab ka nichor ek hi jumla hai: **web pe tum harness kiraye pe lete ho; baad ke courses mein tum harness khud banana seekhte ho.**

Socho jaise ek ready-made furnished ghar aur khud banaya hua ghar — dono mein reh sakte ho, lekin ready-made mein sirf wahi cheezein badal sakte ho jo landlord ne allow ki hain. Baaqi sab uski marzi se chalta hai.

## Zaroori Concepts

### Each later course mapped onto the web surface
Appendices dikhati hain ke loop engineering, harness engineering, evals, runtime jaise concepts kaise nazar aate hain jab agent zyada tar browser ya remote-session environment mein rehta hai.

### On the web you rent a harness; in the later courses you build one
Ye central baat hai. Web products convenience aur ek pre-built (lekin limited) harness dete hain. Baad ke courses tumhe sikhate hain harness khud banao taake control surface tumhara apna ho.

### The five verbs as a lens for what you're renting
Harness Engineering (baad ka course) harness ke kaam ko 5 verbs mein organize karta hai: constrain (kya karne ki ijazat hai), inform (usko zaroori maloomat dena), verify (kaam prove karna), correct (recover karna aur system fix karna), aur escalate (insaan ke paas bhejna). Web pe sirf do ka asal hissa tumhare haath mein hota hai — **inform** (saved instructions aur skills ke through) aur **escalate** (phone pe gate ke through). Baaqi teen — constrain, verify, correct — vendor tumhare liye karta hai, jinhe tum dekh ya badal nahi sakte. Ye table samajhna tumhe batata hai kya vendor pe bharosa kar rahe ho aur kya asal mein tum khud decide kar rahe ho.

### The harness war is industry-wide, not two companies
2026 tak ye jang sirf Claude Cowork vs ChatGPT Work nahi rahi — taqreeban har major lab ne maan liya hai ke competition ab raw model se hat kar harness pe aa gayi hai. Google ka Gemini Spark Gmail, Docs, Workspace mein 24/7 cloud agent hai; Microsoft ka Copilot Tasks Microsoft 365 mein Auto, Researcher, Analyst modes unify karta hai; Meta AI WhatsApp, Messenger, Instagram mein reh kar distribution pe jang lad raha hai. Ek layer neeche managed-runtime front hai (Google ka Gemini Enterprise Agent Platform, Microsoft ka Agent 365) jahan asal masla governance hai — identity, policy, audit — na ke raw capability. Aur sabse door open-engine front hai (DeepSeek V4, Qwen 3.6/3.7, Llama), jahan open weights self-host karna hi wo raasta hai jisse tum poora harness — model samet — apna control kar sako, khaas kar jab regulated data ki wajah se vendor custody chal hi nahi sakti. Same 6-part shape, teen alag fronts.

## Exam Mein Ye Kyun Aayega?

Ye accessible web surface aur baad ki deep engineering ke darmiyan explicit pul hai — exam expect karta hai tum "rent vs build" ka farq samjho.
