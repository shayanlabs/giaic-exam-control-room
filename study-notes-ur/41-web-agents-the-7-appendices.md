# 41. The 7 appendices

## Aasan Zabaan Mein Samjho
Web-agents course 7 chhote appendices pe khatam hota hai, jo baad ke bade courses ke concepts ko web surface pe map karte hain. Ek hi central idea yaad rakho: **web pe tum harness rent karte ho; baad ke courses mein tum khud banate ho.**

Ye contrast hi sabse zaroori cheez hai. Web products convenience dete hain aur ek ready-made (lekin limited) harness dete hain. Deeper courses tumhe sikhate hain harness khud banana taake control surface tumhara apna ho.

## Zaroori Concepts

### Har baad wala course web surface pe map hota hai
Loop engineering, harness engineering, evals, runtime — jab agent mainly browser ya remote-session mein rehta hai, ye concepts kaise dikhte hain, appendices yehi dikhate hain.

### 5 verbs se samjho kya rent kar rahe ho
Harness Engineering course harness ke kaam ko 5 verbs mein baantta hai: constrain (agent kya kar sakta hai limit karna), inform (zaroori info dena), verify (kaam prove karna count hone se pehle), correct (recover karna, phir system fix karna), escalate (insaan ko bhejna). Web pe sirf do ka asli slice milta hai: **inform** — project ki saved instructions aur packaged skills se, aur **escalate** — phone pe gate se. Baaki teen — constrain, verify, correct — vendor karta hai, aisi jagah jahan tum dekh ya badal nahi sakte.

### Harness war ek industry-wide fight hai
2026 tak ye fight sirf do companies tak mehdood nahi — har major lab maan chuka hai ke competition raw model se hat kar harness pe chali gayi hai. Google ka Gemini Spark Gmail, Docs, Workspace mein 24/7 cloud agent hai; Microsoft ka Copilot Tasks Microsoft 365 ke andar Auto, Researcher, Analyst modes unify karta hai; Meta AI distribution pe ladta hai — WhatsApp, Messenger, Instagram ke andar reh kar. Ek layer neeche managed-runtime front hai (Google ka Gemini Enterprise Agent Platform, Microsoft ka Agent 365) jahan asal masla governance hai — identity, policy, audit — capability nahi. Aur sabse door open-engine front hai (DeepSeek V4, Qwen 3.6/3.7, Llama), jahan open weights khud self-host karna hi wo raasta hai jisme tum poora harness, model samet, apna rakh sakte ho — jab regulated ya sensitive data vendor custody ko rule out kar de, ye sabse important ban jaata hai.

## Exam Mein Ye Kyun Aayega?
Ye accessible web surface aur uske baad wale deeper engineering ke beech ka explicit pul hai. Exam mein "rent vs build" ka farq samajh hona chahiye.
