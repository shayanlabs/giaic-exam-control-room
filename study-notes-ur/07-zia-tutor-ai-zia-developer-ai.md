# 7. Zia Tutor AI + Zia Developer AI

## Aasan Zabaan Mein Samjho

Do helpers hain jo dono usi official cookbook se parhte hain. **Zia Tutor AI** dost jaisi teacher hai jo un chat apps ke andar rehti hai jo tum pehle se use karte ho — lessons samjhati hai, sawal poochti hai, aur yaad rakhti hai tum kahan ruke thay. **Zia Developer AI** building partner hai jo coding tools ke andar rehti hai — tum usay problem batao, wo plan likhne aur AI worker banane mein madad karti hai.

Dono cases mein **tum apni khud ki AI brain le kar aate ho**. Ye helpers sirf knowledge aur teaching ya building ka style le kar aate hain — isi liye cost almost zero rehti hai.

## Zaroori Concepts

### Teaching lane (Zia Tutor AI)
Ye connector-native app hai, matlab wo normal Claude (ya jaisa) window ke andar hi kaam karti hai jo tum pehle se use kar rahe ho — kuch naya install nahi karna padta.

### Construction lane (Zia Developer AI)
Ye ek plugin hai jo Claude Code ya OpenCode ke andar rehta hai — wahi jagah jahan asal building hoti hai.

### Connector-native app vs plugin
Connector-native = roz marra ke chat product ke andar kaam karta hai. Plugin = special coding tool ke andar kaam karta hai.

### User model le kar aata hai
Yehi asal money secret hai. Platform tumhare AI tokens ka paisa nahi deta, tum apni khud ki subscription use karte ho. Platform sirf trusted knowledge aur patle helpers serve karta hai — isi liye bina bade bill ke bohot logon tak scale ho sakta hai.

## Exam Mein Ye Kyun Aayega?

Ye do real products hain jo students actually use karte hain — exam mein pochha jayega dono lanes aur cost model kaise kaam karta hai.
