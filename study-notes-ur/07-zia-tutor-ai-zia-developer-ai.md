# 7. Zia Tutor AI + Zia Developer AI

## Aasan Zabaan Mein Samjho

Do helpers hain, aur dono ek hi official kitab se parhte hain — bas kaam alag hai.

**Zia Tutor AI** dost jaisa teacher hai. Ye unhi chat apps ke andar rehta hai jo tum pehle se use karte ho. Lessons samjhata hai, sawal poochta hai, aur yaad rakhta hai tum kahan ruke the.

**Zia Developer AI** building partner hai. Ye coding tools ke andar rehta hai. Tum usay problem batao, wo plan likhne aur AI worker banane mein help karta hai.

Dono cases mein ek cheez common hai: **AI brain tum khud le kar aate ho**. Helpers sirf knowledge aur teaching-ya-building ka tareeqa dete hain. Isi liye cost taqreeban zero rehti hai.

## Zaroori Concepts

### Teaching lane (Zia Tutor AI)
Ye ek connector-native app hai. Matlab wo usi normal Claude (ya waisi hi) window ke andar chalta hai jo tum pehle se open karte ho. Naya kuch install nahi karna parta.

### Construction lane (Zia Developer AI)
Ye ek plugin hai. Claude Code ya OpenCode ke andar rehta hai — jahan asal building hoti hai.

### Connector-native app vs plugin
Connector-native matlab rozmarra chat product ke andar kaam karta hai. Plugin matlab special coding tool ke andar kaam karta hai. Bas itna farq hai.

### User khud model le kar aata hai
Yehi asal secret hai. Platform tumhare AI tokens ka paisa nahi deta — tum apni khud ki subscription use karte ho. Platform sirf trusted knowledge aur patle helpers serve karta hai. Isi wajah se ye bohot saare logon tak bina bhaari bill ke scale kar sakta hai.

## Exam Mein Ye Kyun Aayega?
Ye dono real products hain jo students asal mein use karte hain. Exam mein dono lanes ka farq aur cost model kyun chalta hai — dono clear hone chahiye.
