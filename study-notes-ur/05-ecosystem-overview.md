# 5. Ecosystem overview

## Aasan Zabaan Mein Samjho

Ek hi master source socho — jis par sab bharosa karte hain. Us ek Source se teen darwaze khulte hain:

1. Seekhne walon ke liye ek darwaza
2. Banane walon ke liye ek darwaza
3. Naye versions likhne walon (authors) ke liye ek darwaza

In teeno darwazon ke peeche 4 tool-boxes hain jo sab share karte hain. Aur sab kuch do jagah save hota hai — ek Git folder (asal text) aur ek database (taake computer fast search kar sake).

Sab se dilchasp baat: har user apna khud ka AI brain le kar aata hai, is liye platform ko AI ka bill khud nahi bharna parta. Yahi wajah hai cost taqreeban zero rehti hai.

## Zaroori Concepts

### Ek Source, teen gateways
- **Source**: khud book, jo ek trusted System of Record ban gayi hai.
- **Teen gateways** (darwaze):
  1. Learners Claude (ya waisa hi kuch) khol kar Zia Tutor AI se milte hain.
  2. Builders Claude Code ya OpenCode khol kar Zia Developer AI se milte hain.
  3. Authors ek publishing pipeline use kar ke book ke naye versions banate hain.

### Chaar packages (shared tool-boxes)
- **content** — trusted knowledge
- **learning** — yaad rakhta hai student kahan ruka tha
- **pedagogy** — teaching ka tareeqa (kaise samjhana hai, kab quiz lena hai)
- **builder** — agents banane ke templates aur recipes

### Git + Postgres
Git master text ko sambhalta hai. Postgres (pgvector naam ke special search tool ke saath) fast searchable version sambhalta hai. Book ek baar change karo, baaki sab khud update ho jata hai.

### Near-zero AI cost
Platform AI brain ka paisa nahi deta — har user apni khud ki AI subscription use karta hai. Platform sirf knowledge aur patle darwaze serve karta hai. Isi liye ye bina bhaari bill ke bohot logon tak pohanch sakta hai.
